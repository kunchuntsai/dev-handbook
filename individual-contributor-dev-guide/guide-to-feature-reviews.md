# Guide to Feature Reviews

> [!TIP]
> This is for existing features.
>
> Reference: [Guide to Software Architecture Design Docs](guide-to-software-architecture-design-docs.md)

## Context

With feature reviews, a functional team will increase its knowledge base and spread the knowledge among all members. This review process will help the team grow and benefit the organization.

## Structure

### Design document

- User journey
- Architecture, building blocks
- Pipeline, workflows
- Interfaces and data structures
- Procedures

### Implementation

- Code design/code study

### Verification

- Test cases explanation
- Test reports and known issues
